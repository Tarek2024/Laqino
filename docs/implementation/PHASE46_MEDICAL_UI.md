# Phase 46 — واجهات الروشتات وردود الصيدليات

- أزرار منفصلة لفتح الكاميرا الخلفية واختيار الصور من المعرض؛ كلاهما يستخدم `rxPreview` ومعاينة الصور الحالية.
- قسم «روشتاتي وردود الصيدليات» يظهر مباشرة بعد نموذج الإرسال، ويعرض تاريخ الروشتة وحالتها وردود الصيدليات المسجلة فعليًا.
- قسم استعلامات الأدوية يعرض تاريخ الاستعلام وردود الصيدليات المسجلة.
- تحديث دوري أثناء الخمول لواجهة الخدمات الطبية، مع عدم إعادة رسم النموذج إذا كان العميل يكتب أو توجد ملاحظة/بحث غير محفوظ أو صور مختارة.
- لم تتغير APIs أو قاعدة البيانات أو مسار الدليفري.
- تفاصيل الاختبار وحدوده في `TEST_RESULTS_PHASE46.md`.
