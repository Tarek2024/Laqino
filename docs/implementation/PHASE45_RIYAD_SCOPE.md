# Phase 45 — نطاق مركز الرياض

- واجهة تحديد المنطقة العامة تعرض المحافظة والمركز فقط؛ لم تعد تعرض اختيار القرية.
- اختيارات الفروع القديمة التابعة لـ `eg-kfs-riyad` تُحوّل إلى مركز الرياض عند بدء التطبيق. لا تُحذف سجلات الفروع.
- نتيجة GPS التي تطابق فرعًا تابعًا لمركز الرياض تُرجع المركز. بقية المراكز تحتفظ بسلوك الحل السابق.
- طلبات الخدمات المحلية على مستوى مركز الرياض تشمل مقدمي الخدمة المنشورين في الفروع التابعة له. تشمل المطابقة البحث، والطلبات المفتوحة، وقبول الطلب والتنبيهات.
- APIs الخاصة بالدليفري لم تتغير، واختبارات دورة الدليفري اجتازت التشغيل.
- لا تتوفر في قاعدة البيانات الحالية حدود مضلعة رسمية للمركز؛ يستخدم حل GPS الإحداثيات وأنصاف الأقطار الموجودة. يجب تأكيد الحدود الجغرافية الدقيقة قبل ادعاء أن هذا يمثل الحدود الإدارية الرسمية.
- نتائج الاختبارات: `TEST_RESULTS_PHASE45.md`.
