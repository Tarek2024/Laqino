# Phase 44 — فصل التسجيل عن الدخول

## النطاق
- صفحة تسجيل دخول داخل الواجهة الرئيسية، بدون حقل اسم أو زر إنشاء حساب ضمن نفس النموذج.
- صفحة مستقلة `/register.html` تحتوي الاسم والهاتف وكلمة المرور وتأكيدها.
- إعادة استخدام `/api/register`, `/api/login`, `/api/verify/start` و`/api/verify/status` الموجودة؛ لا توجد جداول أو APIs جديدة.
- دعم تدفق التحقق الحالي عبر واتساب إذا كان مفروضًا من إعدادات الخادم.
- تحديث Service Worker إلى `laqino-v80` وإضافة صفحة التسجيل إلى ملفات shell.

## حماية البيانات والتوافق
- لا توجد ترحيلات لقاعدة البيانات.
- لا يتم تغيير كلمات المرور أو جلسات الحسابات الموجودة.
- لا تُضمّن قاعدة بيانات أو ملفات رفع أو أسرار في الأرشيف.
- لم يُنشر التحديث على السيرفر الأساسي.

## اختبار القبول
راجع `TEST_RESULTS_PHASE44.md` لتفاصيل الفحوصات التي شُغلت ونتائجها وحدود البيئة.
