## القرارات التقنية المعتمدة (لا تُغيَّر دون سبب موثّق)
1. الإبقاء على: Python stdlib + SQLite + واجهة HTML/JS وصفحات PWA. لا Flutter ولا إطار جديد ولا قاعدة جديدة.
2. الوحدات الجديدة تُضاف بنمط `notif.py`: ملف مستقل لا يستورد `server.py`، يُربط بأسطر قليلة. يُسلَّم `server.py` كاملًا عند تعديله.
3. الترحيل عبر `CREATE IF NOT EXISTS`/`ALTER` للإضافات، وإعادة بناء الجدول بنمط `market.py` (نسخة احتياطية أولًا) عند تعديل قيود CHECK.
4. كل واجهة تمر على `esc()`؛ وبعد أي تغيير واجهة يُرفع `V` في `static/sw.js`.
5. كل وحدة بايثون جديدة تُضاف إلى `COPY` في `Dockerfile` وإلى `test_docker_modules.py`.
6. لا يُسلَّم داخل أي ZIP: `laqino.db`، `uploads/`، `.env`، مفاتيح.

7. وحدة `gsearch.py` هي مصدر البحث الشامل (تطبيع عربي موحد `norm`)؛ الأطباء/المعامل/الخدمات ما زالت تُبحث بواجهاتها القائمة ولم تُنقل.

8. وحدة `products.py` (م2) مصدر عروض المنتجات؛ التصنيفات الفرعية للطبي تُنشأ بقرار الإدارة (`/api/admin/products/seed-categories`) لا تلقائيًا؛ مراجعة الإدارة هي الضابط الوحيد لمنع إدراج أدوية كمنتجات.
