# المرحلة 9 — التكامل والإصدار (فحص جاهزية، لا ميزات جديدة)

## 1. النطاق
الوثائق لم تفصّل هذه المرحلة، فاخترت **تثبيت الإصدار بدل إضافة ميزات**: لا تغيير في `server.py` ولا الواجهة ولا قاعدة البيانات (كاش `laqino-v40` كما هو). الهدف أن يكون هذا الـZIP قابلًا للنشر والتحقق منه بأمر واحد.

## 2. ما أُنجز
- `test_phase9_release_smoke.py` (16 فحصًا): يشغّل `server.py` **كعملية مستقلة** (كما على Termux/Docker) على قاعدة مؤقتة، ويتحقق: الإقلاع و`/healthz`، تقديم كل صفحة/أصل في SHELL + اللوحات + الأيقونات + `native.js` (200)، صحة `manifest`، ترويسات الأمان (CSP/nosniff/X-Frame)، رفض اجتياز المسارات وعدم تقديم الكود/القاعدة، إنشاء المدير من البيئة ودخوله، نظرة الإدارة وحالة FCM (مقفولة)، تسجيل عميل ومساراته وصلاحياته (401/403)، **نسخة احتياطية والخادم يعمل** (ملف واحد، قاعدة بلا أسرار)، إعادة تشغيل وبقاء البيانات، ورفض الإقلاع بكلمة مرور مدير ضعيفة.
- `release_check.py` (قراءة فقط، بلا شبكة): الوحدات المستوردة منسوخة في `Dockerfile`، ملفات SHELL موجودة، لا قواعد/`.env`/مفاتيح/حساب خدمة داخل المجلد، README لكل مرحلة 1..9، README بلا رقم كاش قديم، وكل متغير `LAQINO_*` في الكود موثّق.
- `VERSION` = `phase-09`.
- التوثيق: `README.md` أُعيدت كتابته (كان يصف «المهام 1–6» وكاش v27 وحالة APK قديمة؛ القديم محفوظ في `README_HISTORY.md`)، `DEPLOY.md` (+قسم FCM وفحص الإصدار)، `deploy/env.example` (+`LAQINO_FCM_SERVICE_ACCOUNT` مقفول).

## 3. تصحيح لتقرير سابق
تحذير `no such table: listing_reports` في `test_phase7_overview.py` **ليس خللًا**: الاختبار نفسه يمسح الجدول (سطر 55) ليتحقق أن العدّاد يرجع 0 بلا 500. الجدول موجود على أي قاعدة تُهيَّأ (`market.migrate`). سبق أن ذكرته كاحتمال خطأ؛ فُحص وسقط.

## 4. لم يُجرَّب / ما زال مفتوحًا (بصدق)
- **لم يُشغَّل Docker** (لا daemon في بيئتي): `docker compose up --build` لم يُجرَّب فعليًا؛ المغطّى فقط اتساق `Dockerfile` مع الوحدات. لا Termux ولا هاتف حقيقي. لا APK (م8).
- بنود تحتاج قرارك (لم أغيّرها): رقم واتساب الحقيقي داخل `deploy/env.example` (`LAQINO_WA_NUMBER`) — استبدله لو سترفع الملف لمستودع عام؛ `unsafe-inline` في CSP مقصود (الحماية بـ`esc()`)؛ `http.server` يحتاج ترقية مع الحمل الكبير.
- لم أقِس الأداء على بيانات كبيرة ولا اختبرت حملًا متزامنًا.
- الصور المرفوعة قبل المرحلة 14 لم تُنظَّف من EXIF.

## 5. التطبيق
نسخة احتياطية ← فك الـZIP فوق المشروع ← `python3 release_check.py` ← `python3 test_phase9_release_smoke.py` ← إعادة تشغيل الخادم. لا ترحيل جديد. الرجوع: استرجاع `README.md` و`DEPLOY.md` و`deploy/env.example`، وحذف `VERSION` و`release_check.py` و`test_phase9_release_smoke.py` (لا أثر على التشغيل).

## 6. الخطوة التالية
جرّب على جهازك: الإقلاع على Termux أو Docker، ثم الغلاف (م8) وأبلغ بما يظهر. بعدها دفعة 8/2 أو أي بند من القائمة أعلاه.
