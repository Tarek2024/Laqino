# المرحلة 1 — الواجهة والبحث الشامل

## 1. الرقم والاسم والهدف
المرحلة 1: `laqino-phase-01-ui-search`. الهدف: بحث شامل فعلي على بيانات النظام الحقيقية مع تطبيع الحروف العربية، وعرض نتائج مجمّعة حسب النوع.

## 2. الإصدار الأساسي
`Laqino-last-version.zip` (SHA-256 يبدأ بـ `a5d7b5b0bc1ade76`)، مجلد `laqino-phase14`، كاش `laqino-v27`. لا يوجد Git. هذا الـ ZIP **لا يحتوي المشروع كاملًا** ويحتاج تلك النسخة الأساسية (ZIP المرحلة 0 توثيقي فقط ولا يؤثر).

## 3. ما أُنجز فعليًا
- وحدة جديدة `gsearch.py` ومسار عام `GET /api/search?q=&region_id=&limit=` يبحث في: الأدوية (مخزون الصيدليات الحديث والمتوفر)، الصيدليات المعتمدة، إعلانات السوق المعتمدة (العنوان والوصف واسم التصنيف)، التخصصات، أنواع الخدمات. تطبيع عربي: أ/إ/آ=ا، ة=ه، ى=ي، ؤ/ئ، حذف التشكيل والتطويل، أرقام هندية→لاتينية.
- أُصلح عيب المرحلة 0: بحث الأدوية كان `lower()` فقط فلا يطابق «أوجمنتين/اوجمنتين»؛ وبحث السوق كان `LIKE` خامًا.
- `static/index.html`: دالة `gsr()` تستدعي `/api/search` مع الأطباء والمعامل والخدمات (التي تُطبَّع أصلًا)، وتعرض أقسامًا جديدة: الصيدليات، التخصصات (بعدد الأطباء المنشورين)، أنواع الخدمات. فشل أي قسم يُظهر خطأه فقط والبقية تعمل؛ فشل الكل يُظهر زر «حاول تاني»؛ الحالات الفارغة وإخلاء HTML كما كانت.
- `sw.js`: `laqino-v28` وإضافة `/market.html` إلى SHELL.
- `Dockerfile`: إضافة `gsearch.py` لقائمة `COPY` (وإلا ينكسر الخادم في Docker).
- لا أي رقم هاتف (بائع/صيدلية/طبيب) في ردود البحث (مُختبَر).

## 4. ما لم يُنجز
- **إعادة تصميم الواجهة العامة (بطاقات/أزرار/نماذج) لم تُنفَّذ.** الواجهة الحالية RTL وللموبايل أصلًا (أُعيد تصميمها في مراحل سابقة)، ولم أجد في الفحص سببًا لتغييرها دون صور شاشة من هاتفك. قدّم ملاحظاتك البصرية لأعالجها.
- **الكوزمتكس/الأم والطفل/المنتجات:** لا توجد بيانات لها بعد (جدول المنتجات في المرحلة 2). البحث سيشملها حين تُبنى.
- **الأطباء والمعامل والخدمات** لم تُنقل إلى `/api/search`؛ تبقى على واجهاتها (تدعم التطبيع أصلًا).
- فتح النتيجة: الأطباء/التخصصات/المعامل/الخدمات/الأدوية/السوق تفتح قسمها بالبحث نفسه (سلوك قائم). **بطاقة الإعلان لا تفتح صفحة تفاصيل الإعلان نفسه** ولا بطاقة الصيدلية صفحة خاصة (لا توجد صفحة عامة للصيدلية).
- `market.html` لم يُعدَّل (السوق الاختياري)، أُضيف للكاش فقط.

## 6. API/الجداول/الصلاحيات
أُضيف `GET /api/search` (عام بلا تسجيل دخول، كحال `/api/medical/search` و`/api/doctors`). الرد: `{q, region_id, needs_region, medicines[], pharmacies[], listings[], specialties[], service_types[]}`. حد 20 لكل مجموعة، فحص آخر 500 إعلان و1000 صنف مخزون. **لا جداول ولا حقول جديدة ولا ترحيل.** `needs_region=true` بلا منطقة (الأدوية تتطلب منطقة كالسابق).
