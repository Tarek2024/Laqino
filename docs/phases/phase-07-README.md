# المرحلة 7 — لوحة الإدارة الموحدة (نظرة عامة)

## 1. الهدف والافتراضات
الوثائق لم تحدد مطلوب هذه المرحلة تفصيلًا (سطر واحد: «لوحة الإدارة الموحدة»). قرأت اللوحة فوجدتها 20 تبويبًا متفرقًا: المدير لا يعرف أين ينتظره عمل إلا بفتح كل تبويب. فاخترت أضيق نطاق مفيد، وهو **صفحة واحدة تجمع كل ما ينتظر قرارًا**:
- لم أعد تصميم أي تبويب قائم ولا غيّرت أي صلاحية؛ إضافة فقط.
- العدّادات أعداد فقط، بلا أسماء ولا أرقام هواتف.

## 2. ما أُنجز
- وحدة `overview.py` (بنمط svc.py، لا تستورد server.py): `GET /api/admin/overview` (admin وstaff؛ 401/403 لغيرهم؛ قراءة فقط).
- 10 عدّادات «بانتظار القرار»: انضمام مندوبين، شحن المحفظة، إعلانات بانتظار المراجعة، بلاغات الإعلانات، بلاغات المحادثات، طلبات الخدمات المفتوحة، منتجات الصيدليات، انضمام صيدليات، روشتات بانتظار التحويل، طلبات توصيل متنازع عليها. + 5 أرقام عامة (مستخدمون، مندوبون معتمدون، صيدليات معتمدة، إعلانات منشورة، توصيل آخر 24 ساعة).
- كل عدّاد استعلام مستقل: جدول مفقود أو خلل في أحدها يعطي 0 مع سطر في stderr، ولا يُسقط الاستجابة.
- الواجهة: تبويب «نظرة عامة» هو الصفحة الافتتاحية (صار عدد الأقسام 21)، يعرض الأقسام التي فيها بنود فقط، والضغط على الصف يفتح التبويب المعني، وشارة حمراء بالعدد على أزرار التبويبات (تبويب «الإعلانات» يجمع إعلانات + بلاغاتها). كاش v39.

## 4. لم يُنفَّذ / لم يُجرَّب
- لم أُعد تصميم التبويبات الأخرى ولا دمجتها؛ لم أضف بحثًا شاملًا في الإدارة ولا إجراءات جماعية.
- بنود «بانتظار القرار» تُحسب بالحالة فقط (لا عمر ولا أولوية)، فلا تنبيه للمتأخر منها.
- تبويب «تأكيد واتساب» ليس له عدّاد.
- «آخر 24 ساعة» لا «اليوم» كي لا يتأثر بالمنطقة الزمنية.
- جُرّب في Chromium بحجم هاتف (360px) فقط، لا على هاتف حقيقي أو Termux أو Docker.
- العدّادات تُجلب عند كل تنقل بين التبويبات (استعلامات عدّ خفيفة)؛ لم تُقَس على بيانات كبيرة.

## 5. التطبيق
نسخة احتياطية ← فك الـ ZIP فوق المشروع ← `python3 test_phase7_overview.py` ← إعادة تشغيل الخادم. لا ترحيل لقاعدة البيانات (قراءة فقط). الرجوع: استرجاع الملفات المعدّلة وحذف `overview.py`.
