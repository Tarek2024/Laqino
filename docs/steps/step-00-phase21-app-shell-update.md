# تحديث لاقينو — الإصدار phase-21: هيكل التطبيق (App Shell)

**الإصدار:** `phase-21` — **كاش الخدمة:** `laqino-v53` (السابق: `laqino-v52`)
مصدر الرقم الوحيد: ملف `VERSION`. أي إصدار قادم يغيّره هناك أولًا ثم يُشغَّل `python3 check_versions.py`.

تحسين واجهة فقط (CSS + JS للعميل + أصول). لا تغيير في API ولا قاعدة البيانات ولا منطق الطلبات. السطر الوحيد في `server.py`: إضافة نوع `.webp` لجدول MIME.

## ما تغيّر
| البند | التفصيل |
|---|---|
| سلوك النظام | `overscroll-behavior`، منع تحديد النص على الأزرار والتبويبات، `100dvh`، `touch-action:manipulation` |
| هيدر ذكي | كبير في الرئيسية، ومضغوط بعنوان الصفحة وزر رجوع في الصفحات الفرعية. جرس `notif.js` كما هو |
| التبويب السفلي | أيقونات 3D (SVG مضمّن، بلا صور)، النشط ملوّن ومكبّر والباقي رمادي، شارات: نقطة على «السوق» (رسائل) وعدّاد على «حسابي» (طلبات/روشتات/خدمات) من `/api/notifications` الموجود |
| بطاقات الرئيسية | أيقونات 3D للأقسام الأربعة؛ الشاشات الفاضية ببلاطة مجسمة |
| المسكوت | نسخة بخلفية شفافة (`assets/mascot-cut.webp`) في ترويسة الرئيسية وفوق لوحة اختيار المنطقة |
| الحركة | انتقال قصير بين التبويبات، حفظ موضع التمرير لكل تبويب، الضغط على التبويب النشط يرجع للأعلى |
| زر الرجوع | في الجهاز: يقفل لوحة المنطقة ثم يرجع للرئيسية بدل الخروج |
| الاتصال | شريط «مفيش اتصال» وToast عام (`window.laqToast`) |
| سحب للتحديث | على كل التبويبات عند أعلى الصفحة، وبلا تدخل إذا كان المستخدم يكتب أو اللوحة مفتوحة |
| manifest | `shortcuts` (السوق والمحادثات) و`categories` |

## الملفات
- **جديد:** `static/shell.css`، `static/shell.js`، `static/assets/mascot-cut.webp`، `test_phase21_app_shell.py`
- **معدّل:** `static/index.html` (سبرايت 3D + دالة `I3` + ربط الملفات + استبدال أيقونات التبويب والبطاقات ومكان المسكوت)، `static/sw.js` (كاش v53 + الملفات الجديدة)، `static/manifest.webmanifest`، `server.py` (سطر MIME)، `VERSION` والوثائق الأربع.
- **لم تُمَس:** لوحات المندوب والصيدلية والإدارة وسوق السوق (`market.html`).
