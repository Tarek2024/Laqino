# تحديث phase-86 — م5: شاشة طلب العميل (أصناف + أجرة + إجمالي)

> **الحالة الحالية: الإصدار `phase-86` — كاش الخدمة `laqino-v129`** (السابق: `laqino-v128`).
> هذا الـZIP **تراكمي** فوق phase-84 (يضم م4 `phase-85` ومعه م5)؛ تفاصيل م4 في `README_UPDATE_PHASE85.md`.

## اللي اتعمل
- في كارت أوردر المحل (حسابي ← طلباتي) بقى فيه **فاتورة الطلب**: اسم المحل، كل صنف بكميته وسعر الواحد وإجمالي السطر، **ثمن الأصناف**، **أجرة التوصيل**، **الإجمالي**، وملاحظة العميل لو كتب.
- الأجرة بتظهر بعد ما المندوب يقترحها (نفس قاعدة الأجرة الحالية). قبل كده بيظهر «المندوب هيقترحها وانت توافق» والإجمالي المكتوب «حاليًا (بدون التوصيل)». لو العميل رفض الأجرة والأوردر رجع للبحث، الأجرة والإجمالي بيختفوا والأصناف تفضل.
- الأسعار **لقطة وقت الطلب**: لو المحل غيّر سعر صنف بعدين، فاتورة العميل ما تتغيّرش.
- `GET /api/delivery/orders` بيرجّع لأوردرات المحلات فقط: `shop_items[{name,price,qty,line_total}]`، `items_total`، `shop_note`، `shop_name`، `delivery_fee`، `grand_total` (= الأصناف + الأجرة لما الأجرة تظهر، وإلا `null`). الأوردر العادي والصيدلية مفيهمش أي حقل منهم، و`items_json` الخام مش بيتعرض.
- الاسم بيتعرض بـ`esc()` (اختبار بيتأكد إن HTML جوّه اسم الصنف ما بيتنفذش).
- ثمن الأصناف يُحاسَب بين العميل والمحل خارج النظام (زي ما هو في المشروع)؛ الإجمالي للعرض فقط.
