# تحديث phase-82 — م1 «تطوير المحلات»: صور المحلات تظهر للجميع

> **الحالة الحالية: الإصدار `phase-82` — كاش الخدمة `laqino-v125`** (السابق: `laqino-v124`).

## ليه الصور مكانتش بتظهر
1. صفحة المحلات كانت بتجيب كل صورة بـ`fetch` وتوكن تسجيل دخول، فالزائر بلا حساب مكانش بيشوف أي صورة.
2. مفيش كاش للمتصفح (مسار `/api/files` خاص)، وكل صورة طلب مستقل بدون lazy، وأي فشل كان بيتسكت عنه والمكان يفضل فاضي.

## اللي اتعمل
- **مسار عام جديد** `GET /api/shops/<محل>/images/<ملف>` (في `shops.py`، من غير تسجيل دخول، مع `Cache-Control: public, max-age=3600`). بيرجّع الصورة بس لو: المفتاح العام مفعّل، المحل معتمد، المنطقة مفعّلة، الصنف نشط، والملف فعلًا صورة لصنف **في نفس المحل**. غير كده 404 (من غير ما نكشف وجود الملف). `/api/files` وخصوصيته زي ما هم بدون تغيير.
- `server.py`: سطر واحد: `shops.bind(audit, UP)` (مجلد الرفع).
- `static/shops.html`: الصور بقت `<img src>` مباشرة بـ`loading="lazy"` و`decoding="async"`؛ لو الصورة مش موجودة أو فشلت تتبدّل بمربع بأيقونة نوع المحل (🍽️ 🛒 🍰 👕)، وكروت المحلات اللي مالهاش صور كمان بتاخد نفس المربع.
- `static/sw.js` و`VERSION`: الكاش `laqino-v125`، وترويسات الحالة في README/HANDOFF/PROJECT_STATE/STATUS اتحدّثت (كانت قديمة من phase-77 وكان `check_versions` و`release_check` بيفشلوا بسببها قبل التحديث).
- اتحفظ الـREADME القديم باسم `README_UPDATE_PHASE77.md`.

## ملفات التحديث
`shops.py`، `server.py` (سطر واحد)، `static/shops.html`، `static/sw.js`، `VERSION`، `README.md`، `HANDOFF.md`، `PROJECT_STATE.md`، `STATUS.md`، `README_UPDATE.md`، `README_UPDATE_PHASE77.md`، `test_phase82_shop_images.py`.
لم يتغيّر: `shop.html` (لوحة صاحب المحل بتفتح صور أصحابها بتوكنهم كما كانت)، شاشات الدليفري، المحفظة، تسجيل الدخول، القاعدة (لا ترحيل ولا أعمدة جديدة).

## الاختبار
`python3 test_phase82_shop_images.py` (31 فحصًا: مسار الخادم + الصفحة + متصفح Chromium فعلي بحجم هاتف كزائر وكعميل مسجَّل، شامل حالة الصورة المكسورة). الاختبار على Chromium في بيئة التطوير، **وليس على Termux**.

## تطبيق التحديث (Termux)
```
cp -r ~/Laqino ~/Laqino.bak-$(date +%Y%m%d)      # نسخة احتياطية
cd ~/Laqino && unzip -o ~/laqino-phase82-update.zip   # نسخ الملفات المتغيرة فوق المشروع
# أعد تشغيل الخادم؛ لا ترحيل مطلوب. أول فتح للتطبيق يحدّث الكاش تلقائيًا (laqino-v125).
```
## التراجع
استرجع الملفات من النسخة الاحتياطية (`cp -r ~/Laqino.bak-*/* ~/Laqino/`) وأعد تشغيل الخادم. لا تغيير في القاعدة فلا يلزم ترحيل عكسي.
