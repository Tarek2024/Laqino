# تحديث phase-87 — الطلب المباشر من الصيدلية (قسم المنتجات) + إصلاح بث الإشعارات

> الإصدار `phase-87` — كاش الخدمة `laqino-v130`. التحديث فوق phase-86 (تفاصيل م5 في `README_UPDATE_PHASE86.md`).

## 1) اطلب من الصيدلية مباشرة ← يتحول دليفري
- العميل في «المنتجات» (أو صفحة الصيدلية): زر **«اطلب من الصيدلية»** على كل منتج ← شريط سلة ← ورقة الطلب (كميات + عنوان + ملاحظة) ← «ابعت الطلب للصيدلية». سلة صيدلية واحدة في كل مرة.
- الطلب يوصل الصيدلية «جديد» (إشعار جرس + Push). **لا يُرسَل مندوب قبل ما الصيدلية تقبل.**
- الصيدلية (لوحتها ← الطلبات ← «طلبات المنتجات»): **قبول** ← يتحول فورًا لطلب توصيل عادي (`origin_type=product_order`) ويبحث له النظام عن مندوب ← **جاهز للاستلام**، أو **اعتذار** (قبل القبول أو بعده وقبل استلام المندوب؛ بعد القبول يُلغى الدليفري).
- العميل في «حسابي ← طلباتي»: قبل الرد كارت «بانتظار رد الصيدلية» (مع إلغاء)، وبعد القبول قايمة المراحل والفاتورة (أصناف + أجرة + إجمالي) واسم/رقم المندوب. الأجرة يقترحها المندوب ويوافق عليها العميل كباقي الطلبات.
- الأسعار لقطة وقت الطلب. الصيدلية لا ترى عنوان/هاتف العميل. ثمن المنتجات يُحاسَب بين العميل والصيدلية.
- الشرط: مفتاح المنتجات `products_enabled` شغّال، وأجرة منطقة الصيدلية مضبوطة.
- سقوف: 5 طلبات «جديدة» معلّقة، 10 طلبات/ساعة، 20 صنف، كمية حتى 20.

## 2) إصلاح الإشعارات
