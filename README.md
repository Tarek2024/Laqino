# لاقينو 15 — الإصدار phase-35 (مشروع كامل تراكمي)

> **الحالة الحالية: الإصدار `phase-39` — كاش الخدمة `laqino-v71`** (المرجع الوحيد: ملف `VERSION`). أي رقم إصدار أو كاش أقدم في هذا الملف سجل تاريخي لمراحل سابقة. عدد تبويبات الإدارة الآن 23. مجلد المشروع: `laqino-15`.


تطبيق ويب عربي (PWA) لمنطقة محلية: سوق إعلانات بمحادثة، خدمات طبية (أدوية، روشتات بتسعيرة، صيدليات ومنتجاتها، أطباء، معامل)، خدمات محلية بحسابات مقدمين وتقييمات، وتوصيل بمندوبين، ولوحة إدارة موحدة. السيرفر Python (مكتبة قياسية + `cryptography` للإشعارات) وSQLite.
هذا الـZIP **مشروع كامل** (الأساس + المراحل 1–20). لا يحوي `laqino.db` ولا `uploads/` ولا أسرارًا — عمدًا. التفاصيل: `docs/CONSOLIDATED_REPORT.md` وملف لكل مرحلة في `docs/phases/`، والحالة في `PROJECT_STATE.md` و`HANDOFF.md`.

## ما يحويه المشروع الآن (ملخص المراحل 1–20)
- **الخطوات 1–5 و7** (`docs/steps/`): صور الشات وسجل اطلاع الإدارة • طلب الخدمة الموسّع (صور وعنوان وميزانية والحالات الـ11) • عروض أسعار الخدمات باعتماد الإدارة واختيار العميل وفتح النزاع وحسمه • الروشتات متعددة الصور مع اعتماد الإدارة لردود الصيدليات • تقييم الخدمات وبلاغات التقييم • إشعارات الإدارة والصيدليات.
- **سوق الصيدليات** (`phase-09s7x`): بيع دواء فائض بخصم بين الصيدليات المعتمدة فقط، حجز ذري، مراجعة الإدارة. **المفضلة والإبلاغ** عن إعلانات السوق (`lsocial.py`).
- **المرحلة 8:** إشعارات أندرويد عبر FCM (`fcm.py` و`static/native.js` وهيكل `android/`، لم يُبنَ APK).
- **المرحلة 10:** توزيع الدليفري بعروض وحضور المندوب (Heartbeat)، الأطباء، وإيقاظ المندوب بـWeb Push.
- **المرحلة 11:** ترويسة CSP، تنقل جديد وبحث عام من الرئيسية، الخدمات المحلية بمقدميها، معامل التحاليل، ونسخ احتياطي واستعادة (`backup_restore.py`). إلى جانبها: استعادة كلمة المرور بكود من الإدارة، والتحقق من الهاتف عبر واتساب (اختياري).
- **المرحلة 14:** تقوية أمنية: أرقام الأطباء والمعامل خلف تسجيل الدخول وبسقف ساعي، إزالة EXIF/GPS من الصور، HSTS، وفحص كلمة مرور المدير.
- **المرحلتان 15–16:** إصلاح ظهور أقسام لوحة الإدارة على الهاتف، صور الأطباء والمعامل، وحسابات المندوبين ومحفظتهم من لوحة الإدارة (`test_phase16_*`).
- **المراحل 17–19:** واجهات متجاوبة موحّدة (`theme.css`)، إدارة أقسام الرئيسية من تبويب «الأقسام والواجهة» (`/api/home-sections`)، والرئيسية بأربع بطاقات: الخدمات الطبية، سوق لاقينو، الخدمات المحلية، التوصيل (المنتجات داخل «الطبي»).
- **المرحلة 22 (الحالية): الموقع الموحد.** طلب GPS مرة واحدة عند الفتح وحفظه على الجهاز وربطه بنظام المنطقة الحالي (يخدم السوق والأطباء والمعامل والخدمات والطبي والتوصيل)، ملء «عنوان التسليم» تلقائيًا في التوصيل مع إمكانية التعديل أو الإزالة، زر «حدّد موقعي» في نافذة المنطقة، وإحداثيات المناطق من لوحة الإدارة. بلا تتبع مستمر، والاختيار اليدوي كما هو عند الرفض. التفاصيل: `README_UPDATE.md` و`docs/steps/step-08-unified-location.md`.
- **المرحلة 20:** إصلاحات بصرية فقط: مربعات الاختيار في لوحة الإدارة، محاذاة تبويب «الأقسام والواجهة»، تبويبات «الطبي»، وعنوان لوحة الصيدلية/المندوب على الهاتف. لوحة الإدارة فيها الآن 23 تبويبًا. التفاصيل في `README_UPDATE.md` و`CHANGELOG.md`.

## مرجع الإصدار
ملف `VERSION` هو المصدر الوحيد لرقم الإصدار واسم الكاش (`release=` و`cache=`). عند أي تحديث: غيّره أولًا ثم شغّل `python3 check_versions.py` (يطابقه مع `sw.js` ومع أول ملفات الحالة) و`python3 release_check.py`.

## الخطوات الباقية وما لم يُختبر
- الخطوات الباقية حسب `docs/ROADMAP.md` (محدَّث حتى الخطوة 7): الخطوة 6 (صلاحيات الموظفين + نزاعات الخدمات والسوق) لم تُنفَّذ، وبناء APK وتجربته على جهاز.
- لم يُجرَّب على أجهزة حقيقية: Termux وSafari/iOS وWeb Push وFCM الحقيقيان وDocker وواتساب Meta.
- في آخر تحديث لم تُشغَّل مجموعة الاختبارات كاملة؛ اختبارات مثل `test_exchange_browser` و`test_backup_restore` و`test_courier_documents_ui` تحتاج إعادة تشغيل في بيئتك المعتادة.

## ⚠️ قبل الاستبدال (مهم)
1. أوقف السيرفر وخذ نسخة احتياطية: `python3 backup_restore.py backup --out ~/laqino-backups --keep 14` (أو انسخ المجلد كله).
2. فك الـZIP فوق المجلد القديم (لا يحوي أي قاعدة أو صور فلن تُمسح) أو في مكان جديد وانسخ إليه `laqino.db` (و`-wal`/`-shm`) و`uploads/`.
3. شغّل السيرفر: الجداول الجديدة تُنشأ تلقائيًا وبلا لمس بياناتك. أغلق التطبيق على الهاتف وافتحه مرتين ليأخذ الكاش الجديد (رقمه في `VERSION`).
   - **الخطوة 2:** جدول `service_requests` يُعاد بناؤه تلقائيًا مرة واحدة (صفوفك تنتقل كما هي). **خذ نسخة احتياطية قبل أول تشغيل.** التفاصيل: `docs/steps/step-02-service-requests.md`.
4. الرجوع: أوقف السيرفر، استرجع الملفات القديمة (أو `backup_restore.py restore --file ... --force`).

## التشغيل
- Python 3.10+. `pip install cryptography` (مطلوب لإشعارات Web Push وFCM).
- `LAQINO_ADMIN_PHONE=01XXXXXXXXX LAQINO_ADMIN_PASSWORD='كلمة-قوية-10-أحرف-فأكثر' python3 server.py` ثم `http://localhost:8000` (بيانات الأدمن تُستخدم فقط إن لم يكن هناك أدمن).
- المتغيرات: `HOST` `PORT` `LAQINO_DB` `LAQINO_UPLOADS` `LAQINO_ADMIN_PHONE` `LAQINO_ADMIN_PASSWORD` `LAQINO_REG_PER_HOUR` `LAQINO_REG_PER_DAY` `LAQINO_WA_VERIFY` `LAQINO_WA_NUMBER` `LAQINO_WA_VERIFY_TOKEN` `LAQINO_WA_APP_SECRET` `LAQINO_VAPID_SUBJECT` و**`LAQINO_FCM_SERVICE_ACCOUNT`** (مسار ملف حساب خدمة Firebase لإشعارات تطبيق أندرويد؛ بدونه الميزة مقفولة). متغيرات الاختبار فقط: `LAQINO_PUSH_ALLOW_ANY`، `LAQINO_TEST_PRESENCE`، `LAQINO_FCM_ALLOW_ANY`، `LAQINO_FCM_BASE`.
- Docker + HTTPS تلقائي (Caddy): `cp deploy/env.example .env` ثم `docker compose up -d --build` — الخطوات والنسخ الاحتياطي في `DEPLOY.md`.
- الصفحات: `/` (العميل) • `/market.html` • `/courier.html` • `/pharmacy.html` • `/admin.html`.

## الاختبارات وفحص الإصدار
كل اختبار ملف مستقل يشغّل سيرفرًا على **قاعدة مؤقتة** ولا يلمس قاعدتك:
```
for t in test_*.py; do echo $t; python3 $t | tail -1; done
python3 release_check.py          # جاهزية الإصدار: وحدات Dockerfile، SHELL، أسرار، توثيق، متغيرات البيئة
python3 check_versions.py          # الإصدار والكاش متطابقان في VERSION وsw.js وملفات الحالة
```
`test_phase9_release_smoke.py` يشغّل `server.py` كعملية مستقلة ويمرّ على الصفحات والترويسات والدخول والنسخ الاحتياطي وإعادة التشغيل. اختبارات المتصفح تحتاج `pip install playwright` + Chromium، وبعضها `node`. `test_docker_modules.py` يتأكد أن كل وحدة بايثون منسوخة في `Dockerfile`.

## أندرويد
`android/` هيكل غلاف Capacitor يفتح موقعك ويضيف إشعارات FCM (`static/native.js`)، **لم يُبنَ ولم يُجرَّب على جهاز**؛ الخطوات في `android/README_ANDROID.md`. السيرفر نفسه لا يعمل داخل التطبيق ويحتاج دومين HTTPS (Docker + Caddy). Termux للتجربة المحلية فقط. بدون APK، الـPWA تعمل بالتثبيت من المتصفح.
