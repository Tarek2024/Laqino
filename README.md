# لاقينو — الإصدار phase-103 (مشروع كامل تراكمي)

> **الحالة الحالية:** الإصدار `phase-103` — كاش الخدمة `laqino-v150`. المرجع الرقمي الوحيد هو `VERSION`، ويجب أن يطابق `static/sw.js`.

## تحديث phase-103 — تحميل قابل للإلغاء وتوقيت حملات القاهرة

- مهلة طلبات بيانات الرئيسية تلغي طلب الشبكة نفسه عبر AbortController بدل ترك اتصالات معلّقة بعد انتهاء المهلة.
- عند رصد عطل، يظهر خيار اختياري لإرسال آخر 10 سجلات تشخيصية إلى دعم لاقينو عبر واتساب؛ لا يفتح إلا بعد تأكيد المستخدم.
- حساب بداية/نهاية الحملات يعتمد المنطقة الزمنية المسماة Africa/Cairo وقواعد التوقيت الصيفي بدل فرق UTC+2 ثابت.
- توحيد اختبار حدود جدولة الحملات مع دالة التاريخ المحلية المستخدمة في الخادم.
- تحديث كاش الواجهة إلى laqino-v150.
- التحديث ما زال على فرع مراجعة ولم يُدمج أو يُنشر.

## تحديث phase-103 — بحث أولًا وحماية فتح الرئيسية

- تقديم شريط البحث إلى أعلى الرئيسية، ثم لوحة الإعلان الإدارية المدموجة بالماسكوت، ثم الأقسام الأساسية.
- إبقاء الأيقونات الأربعة ومفاتيح الأقسام وترتيبها وروابطها ووظائفها كما هي.
- عرض هيكل الرئيسية فورًا دون انتظار طلبات الشبكة؛ تحميل الحملات والإعلانات والخدمات وبيانات الحساب في الخلفية.
- إضافة غلاف عرض احتياطي عند فشل تكوين الرئيسية، وسجل تشخيصي يحدد مرحلة الفشل ورسالة الخطأ واسم واجهة API.
- الإعلانات الإدارية منفصلة عن إعلانات المستخدمين في السوق؛ السوق بديل عرض فقط عند عدم وجود حملة إدارية نشطة.
- تحديث اختبارات الواجهة لتغطي ترتيب العناصر، تأخر/فشل الشبكة، واستجابة المقاسات.
- لم يُدمج التحديث ولم يُنشر؛ يلزم اجتياز مجموعات اختبارات CI الأربع قبل الاعتماد.

تطبيق ويب عربي (PWA) لمنطقة محلية: سوق إعلانات بمحادثة، خدمات طبية (أدوية وروشتات وصيدليات ومنتجاتها وأطباء ومعامل)، خدمات محلية بحسابات مقدّمين وتقييمات، وتوصيل بمندوبين، ولوحة إدارة موحدة. الخادم Python وقاعدة البيانات SQLite.

هذا المستودع يحتوي المشروع التراكمي وسجل مراحله. لا يحوي قاعدة الإنتاج أو مجلد الرفع أو الأسرار عمدًا. تفاصيل الحالة الحالية في `PROJECT_STATE.md` و`STATUS.md`، وآخر تغييرات الفرع في `README_UPDATE.md`، وتعليمات التسليم في `HANDOFF.md`.

> **تنبيه:** أرقام المراحل القديمة ونتائج الاختبارات المسجلة في بقية هذا الملف تاريخية؛ لا تصف تلقائيًا الإصدار الحالي ولا تثبت نجاح اختبارات حديثة. راجع `STATUS.md` ونتائج CI المرتبطة بآخر commit.

## تحديث phase-99 — رابط دعم واتساب هادئ داخل حسابي

## سجل phase-98 — إصلاح أقسام حسابي وتحديث الدليفري الجزئي

- توحيد مفتاح حفظ واستعادة حالة أقسام «حسابي»؛ تظل الأقسام المفتوحة مفتوحة بعد إعادة رسم صفحة الحساب.
- استبدال إعادة رسم صفحة الحساب كل 8 ثوانٍ بتحديث جزئي لبطاقات الطلبات الجارية والسابقة فقط؛ لا يعاد إنشاء عناصر الأقسام أو فقد حالة فتحها.
- حماية التحديث الجزئي من استبدال بطاقة يجري المستخدم التفاعل معها، مع تحديث حالة الطلبات وانتقال المكتمل والملغي للأرشيف.
- صفحة الدليفري ومراحل الطلب وثوابت `STEP` و`LIVE` و`BP` والموقع/GPS خارج نطاق التغيير.

## ⚠️ قبل الاستبدال (مهم)
1. أوقف السيرفر وخذ نسخة احتياطية: `python3 backup_restore.py backup --out ~/laqino-backups --keep 14` (أو انسخ المجلد كله).
2. فك الـZIP فوق المجلد القديم (لا يحوي أي قاعدة أو صور فلن تُمسح) أو في مكان جديد وانسخ إليه `laqino.db` (و`-wal`/`-shm`) و`uploads/`.
3. شغّل السيرفر: الجداول الجديدة تُنشأ تلقائيًا وبلا لمس بياناتك. أغلق التطبيق على الهاتف وافتحه مرتين ليأخذ الكاش الجديد (رقمه في `VERSION`).
   - **الخطوة 2:** جدول `service_requests` يُعاد بناؤه تلقائيًا مرة واحدة (صفوفك تنتقل كما هي). **خذ نسخة احتياطية قبل أول تشغيل.** التفاصيل: `docs/steps/step-02-service-requests.md`.
4. الرجوع: أوقف السيرفر، استرجع الملفات القديمة (أو `backup_restore.py restore --file ... --force`).

## التشغيل
- Python 3.10+. `pip install cryptography` (مطلوب لإشعارات Web Push وFCM).
- `LAQINO_ADMIN_PHONE=01XXXXXXXXX LAQINO_ADMIN_PASSWORD='كلمة-قوية-10-أحرف-فأكثر' python3 server.py` ثم `http://localhost:8000` (بيانات الأدمن تُستخدم فقط إن لم يكن هناك أدمن).
- المتغيرات: `HOST` `PORT` `LAQINO_DB` `LAQINO_UPLOADS` `LAQINO_ADMIN_PHONE` `LAQINO_ADMIN_PASSWORD` `LAQINO_REG_PER_HOUR` `LAQINO_REG_PER_DAY` `LAQINO_WA_VERIFY` `LAQINO_WA_NUMBER` `LAQINO_WA_VERIFY_TOKEN` `LAQINO_WA_APP_SECRET` `LAQINO_VAPID_SUBJECT` و**`LAQINO_FCM_SERVICE_ACCOUNT`** (مسار ملف حساب خدمة Firebase لإشعارات تطبيق أندرويد؛ بدونه الميزة مقفولة). متغيرات الاختبار فقط: `LAQINO_PUSH_ALLOW_ANY`، `LAQINO_TEST_PRESENCE`، `LAQINO_FCM_ALLOW_ANY`، `LAQINO_FCM_BASE`.
- Docker + HTTPS تلقائي (Caddy): `cp deploy/env.example .env` ثم `docker compose up -d --build` — الخطوات والنسخ الاحتياطي في `DEPLOY.md`.
- الصفحات: `/` (العميل) • `/market.html` • `/courier.html` • `/pharmacy.html` • `/admin.html`.

## الاختبارات وفحص الإصدار
كل اختبار ملف مستقل يشغّل سيرفرًا على **قاعدة مؤقتة** ولا يلمس قاعدتك:
```
for t in test_*.py; do echo $t; python3 $t | tail -1; done
python3 release_check.py          # جاهزية الإصدار: وحدات Dockerfile، SHELL، أسرار، توثيق، متغيرات البيئة
python3 check_versions.py          # الإصدار والكاش متطابقان في VERSION وsw.js وملفات الحالة
```
`test_phase9_release_smoke.py` يشغّل `server.py` كعملية مستقلة ويمرّ على الصفحات والترويسات والدخول والنسخ الاحتياطي وإعادة التشغيل. اختبارات المتصفح تحتاج `pip install playwright` + Chromium، وبعضها `node`. `test_docker_modules.py` يتأكد أن كل وحدة بايثون منسوخة في `Dockerfile`.
